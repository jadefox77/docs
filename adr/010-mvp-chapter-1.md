# ADR-010: MVP: a polished Chapter 1 vertical slice

- **Status:** Proposed
- **Date:** 2026-11-01

## Context
A large game needs an early, honest test of whether it is fun.

## Decision
The MVP is Chapter 1 with two protagonists, combat, 2-3 missions, one side activity, a crowd, a reputation track and cloud save. Stretch target March-April 2027 with placeholders; safer estimate September-November 2027. A fun gate with Nigerian playtesters comes before scaling up. The full story stays in scope after the MVP.

## Alternatives considered
- **Build the whole campaign first:** no early feedback; high risk of building the wrong game.

## Consequences
- An MVP feature spec fixes the missions and mechanics.
- Production scales up only if the fun gate passes.

## Revisit if
Playtests fail the fun gate; then redesign before adding content.
