# docs

Design documents, Architecture Decision Records, feature specs, art bible and asset provenance log.

## Layout
- `adr/` - Architecture Decision Records (ADR-001 onward)
- `specs/` - feature specs, one per feature or milestone
- `provenance.md` - every third-party or base asset: source, licence, date, where used

## Rule
Agreed decisions are never changed silently; a change gets a new ADR.
